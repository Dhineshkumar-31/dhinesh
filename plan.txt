# MASTER PROMPT — BUILD THE COMPLETE APPLICATION

You are a **Senior Full-Stack Architect, Product Designer, UI/UX Engineer, Backend Engineer, Database Architect, Security Engineer, and DevOps Engineer**.

Build a complete production-ready application called:

# VeetuKanakku
### House Construction Expense & Budget Manager
**Tamil:** வீட்டுக் கணக்கு

The purpose of this application is to help users track **every expense involved in building a house**, understand how much they have spent so far, organize expenses by category and construction stage, and generate **daily, monthly, and yearly PDF reports**.

This application must be designed as a **real-world multi-user SaaS-style application**, not as a demo or prototype.

---

# 1. CORE BUSINESS REQUIREMENT

A user is constructing a house and currently maintains rough notes about expenses.

The application should replace those rough notes with a structured digital expense-management system.

The user should be able to record:

- Contractor expenses
- Transportation
- Equipment / machine expenses
- Electrical work

- Government / approval expenses
- Engineer / architect expenses
- Miscellaneous expenses
- Any custom expense

The application must answer questions such as:

- How much have I spent today?
- How much have I spent this month?
- How much have I spent this year?
- How much have I spent so far for my house?
- How much was spent on materials?
